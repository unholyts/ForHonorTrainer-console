# For Honor Trainer — консольная версия

Автономная программа для Windows x64. Графической панели нет: управление через F8/F10, состояние отображается в консоли. Установка .NET для готового EXE не нужна.

## Запуск готовой программы

1. Распакуйте весь архив.
2. Оставьте `settings.json` рядом с `ForHonorTrainer.Console.exe`.
3. Запустите `ForHonorTrainer.Console.exe` на ПК игрока, который должен выполнять атаки.
4. Переключитесь в For Honor, выберите персонажа, захватите цель и нажмите **F8**.
5. **F8** останавливает и снова запускает повторы; **F10** завершает программу. В консоли также работает **Ctrl+C**.

Программа запускается остановленной. Нажатия отправляются, только пока активное окно принадлежит указанному процессу игры. При смене окна серия прерывается; после возвращения к игре начинается новый цикл. При остановке уже нажатая кнопка отпускается.

## Текущая последовательность

ПКМ → 800 мс → ПКМ → с вероятностью 50% нажать E через 300 мс от второго ПКМ.

Пауза после финта с E — 1500 мс; после удара без E — 3000 мс. Это прежняя логика программы. Профилей Kyoshin, случайного дилея и переназначения клавиш в этой версии ещё нет.

## Настройки

Остановите повторы клавишей F8, измените `settings.json` в текстовом редакторе и сохраните. При следующем F8 файл перечитывается.

| Параметр | Назначение |
| --- | --- |
| `FirstToSecondClickMs` | Интервал между началами двух нажатий ПКМ, мс |
| `SecondClickToEMs` | Интервал от начала второго ПКМ до E, мс |
| `ClickHoldMs`, `KeyHoldMs` | Удержание кнопки мыши и E, мс |
| `EProbabilityPercent` | Вероятность финта: 0 — никогда, 100 — всегда |
| `PauseBetweenCyclesMs` | Пауза после цикла с финтом, мс |
| `PauseAfterCommittedMs` | Пауза после цикла без финта, мс |
| `GameProcessName` | Имя процесса игры, по умолчанию `forhonor` |

## Проверка без ввода в игру

В PowerShell из папки с EXE:

```powershell
.\ForHonorTrainer.Console.exe --dry-run 10
```

Команда только печатает выбранные действия и завершает работу; кнопки не нажимаются. Справка: `--help`.

## Исходники и самостоятельная сборка

Полный код находится в `source`: `TrainerEngine.cs` содержит настройки, ввод и выполнение циклов; `Program.cs` — консоль и горячие клавиши. Используются только встроенные библиотеки .NET и Windows API. Нужен .NET SDK 7 для Windows.

Из папки `source`:

```powershell
dotnet build .\ForHonorTrainer.Console.csproj -c Release
dotnet publish .\ForHonorTrainer.Console.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true --source https://api.nuget.org/v3/index.json -o ..\publish
```

Готовый EXE автономный; файл настроек остаётся внешним.

Программа управляет текущим игроком, не распознаёт атаки противника и не парирует автоматически. Для тренировки второй игрок парирует атаки вручную. Работу синтетического ввода в игре нужно проверять отдельно; способ ввода — обычный Windows SendInput, без чтения памяти или внедрения в процесс.
